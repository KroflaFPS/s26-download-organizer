# S26 Ultra Download Organizer

An automated, local background file organizer for Samsung Galaxy S26 Ultra (Android 15+).

The app monitors the device's `/Download/` directory, detects when files finish downloading, inspects the file contents (parsing APK metadata, document keywords, and media types), and dynamically routes them to dedicated folders.
